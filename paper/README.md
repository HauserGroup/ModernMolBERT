# Manuscript revision workspace

The active manuscript is edited in the separate manuscript repository. The
published manuscript is retained here as `published_manuscript.pdf`.

The only revision tracker is `MASTER_REVISION_PLAN.md` at the root of the
manuscript repository. It records submission gates, retraining dependencies,
completed evidence and optional work. Do not create a second plan here.

Executable recipes and run evidence remain in `../docs/revision_run.md`,
`../docs/revision_run_record.md` and `../docs/model_retraining_requirement.md`.
Synchronise manuscript source and assets here only as an intentional release step.
